# 🛒 Sistema de Gerenciamento de Produtos simples em Python

Este projeto consiste em um script dinâmico e interativo desenvolvido em Python para gerenciar de forma simples e direta uma lista de produtos e seus respectivos preços.

## 🚀 Funcionalidades

O projeto está estruturado em três partes principais:

1. **Visualização Inicial (Parte 1):** Apresenta uma listagem limpa e organizada dos produtos inicialmente cadastrados e seus valores associados.
2. **Cadastro Interativo (Parte 2):** Permite ao usuário cadastrar dinamicamente novos produtos informando o nome e o preço, atualizando a base de dados instantaneamente.
3. **Remoção e Atualização (Parte 3):** Demonstra a remoção do último produto adicionado através do método `.pop()`, exibindo a lista final atualizada.

## 🛠️ Tecnologias Utilizadas

* **Python 3**: Linguagem base para desenvolvimento da lógica do sistema.
* **Estruturas de Dados (`List`)**: Utilizadas para armazenar e manipular dinamicamente os nomes e preços dos produtos.
* **Funções Integradas (`zip`, `input`, `float`)**: Utilizadas para associar as listas de forma simples e gerenciar a entrada de dados do usuário.
